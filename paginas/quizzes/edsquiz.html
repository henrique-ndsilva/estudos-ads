1. Sobre o Ciclo de Vida na Engenharia de Sistemas, leia as afirmativas abaixo e assinale a alternativa correta.
I - A etapa de Aquisição é o momento onde os requisitos são estabelecidos e decisões de compra de insumos são decididas.
II - A etapa de Desenvolvimento é onde ocorre a implementação de testes e monitoramento do sistema em produção.
III - A etapa de Operação é onde ocorre a implantação e o sistema é colocado em uso.

Resposta Correta: I e III.

2. Assinale a alternativa correta a que se refere à seguinte descrição: "Adequada quando não há um conhecimento da totalidade da solução. Esta estratégia requer uma solução que de maneira geral cubra os requisitos, mas pode perder alguns detalhes..."

Resposta Correta: Estratégia iterativa.

3. Assinale a alternativa correta a que se refere à seguinte descrição: "A principal razão para escolher esta estratégia... é a de agregar valores ao negócio antes do ciclo de vida do projeto encerrar..."

Resposta Correta: Estratégia incremental.

4. O documento de visão é um artefato importante, pois:

Resposta Correta: Pode ser utilizado como base de contratação para desenvolvimento de sistemas.

5. Os membros de um grupo de desenvolvimento de software estão realizando testes em um software baseando-se nos códigos-fonte. Isso envolve a realização de testes em todos os componentes de forma individual, bem como testes das interfaces entre esses componentes quando passam a ser integrados para formar o software. Quais são os tipos de testes que estão sendo aplicados nesse contexto?

Resposta Correta: Unidade e integração.

6. Leia atentamente e analise as afirmativas a seguir:
I. No paradigma conhecido como ciclo de vida clássico ou cascata, a especificação pode ser desenvolvida gradativamente...
II. O modelo espiral é um modelo de processo guiado por risco...
III. O único motivo para altas taxas de falhas em projetos desenvolvidos adotando-se modelos em cascata é a suposição falsa de que as especificações são previsíveis e estáveis.
São corretas APENAS as afirmativas:

Resposta Correta: Somente a II.

7. Um engenheiro de software foi designado para avaliar o processo de revisão por pares que foi adotado para apoiar o desenvolvimento de um novo produto. Essa tarefa seria considerada:

Resposta Correta: Garantia de qualidade.

8. Assinale corretamente o tipo de manutenção na qual se busca modificar o software a fim de torná-lo mais fácil de ser corrigido, adaptado e melhorado:

Resposta Correta: Preventiva.

9. Analise as afirmativas:
I. O processo de validação determina se os artefatos atendem aos requisitos anteriores, enquanto a verificação determina se o produto final atende ao uso pretendido.
II. O teste estrutural requer o conhecimento do código-fonte do software para a elaboração dos casos de teste.
III. A fase de manutenção tem como objetivo exclusivamente tratar da correção de erros e defeitos após a implantação.
Está(ão) correta(s):

Resposta Correta: Somente a afirmativa II é verdadeira.

10. O padrão de arquitetura conhecido como MVC (Model-View-Controller) é útil para o projeto de sistemas que têm interface gráfica com usuário porque:

Resposta Correta: A aparência e o comportamento podem ser modificados sem a modificação do modelo de dados subjacente.

11. Sobre a definição e o foco da Engenharia de Software, assinale a alternativa correta:

Resposta Correta: Tem como foco principal estabelecer uma abordagem sistemática de desenvolvimento, através de ferramentas e técnicas apropriadas, dependendo do problema a ser abordado, considerando restrições e recursos disponíveis.

12. Considere as afirmativas sobre Projeto arquitetural:
I. Podemos trabalhar projetos arquiteturais em diferentes níveis de abstração.
II. Projetos arquiteturais são utilizados para minimizar o reuso de artefatos.
III. Os diagramas podem auxiliar na comunicação com stakeholders.
IV. Sempre usamos UML para fazer projetos arquiteturais.

Resposta Correta: Somente I e III estão corretas.

13. Assinale a opção correta acerca de modelos de processo de software:
I. Segundo o Manifesto Ágil os processos valorizam mais: indivíduos e interações do que processos e ferramentas; software funcionando do que documentação extensa...
II. A programação extrema (XP) permite a ausência do cliente em fases iniciais.
III. A programação em pares está presente sempre em todos os processos ágeis, como XP e Scrum.

Resposta Correta: Apenas a afirmativa I é verdadeira.

14. Em um sistema de gestão de pessoal, quais dos itens abaixo correspondem a requisitos NÃO funcionais?

Resposta Correta: Tempo de resposta das consultas não deve superar 10 segundos e a entrega do produto final não pode ultrapassar o prazo de oito meses.

15. Sobre a engenharia de requisitos, considere as afirmativas:
I. Precisa ser adaptada às necessidades do processo, projeto, produto e pessoal.
II. No levantamento e análise, a equipe técnica trabalha com o cliente para descobrir serviços, desempenho e restrições.
III. Na medida em que a informação de vários pontos de vista é coletada, os requisitos emergentes são consistentes.
IV. A validação de requisitos se ocupa de mostrar que estes realmente definem o sistema que o cliente deseja.

Resposta Correta: Somente as afirmativas I, II e IV são corretas.

16. No modelo de processo SCRUM, o software é desenvolvido em uma série de ciclos iterativos denominados:

Resposta Correta: Sprint.

17. O teste de regressão consiste em:

Resposta Correta: Identificar se as alterações no código-fonte não introduziram novos erros através de uma nova execução da massa de teste anterior.

18. Assinale a alternativa que apresenta as quatro fases do RUP (Unified Process), na ordem cronológica de execução:

Resposta Correta: Concepção, elaboração, construção e transição.

19. Sobre Diagramas de Interação, podemos afirmar que:

Resposta Correta: São elaborados para representar aspectos dinâmicos do sistema como troca de mensagens.
